# Mohamed Abdelwahab — Portfolio Website

Source for the public GitHub Pages portfolio at [Mohamed3bdelwahab.github.io](https://Mohamed3bdelwahab.github.io).

The site presents automation consulting, Agentic AI, RPA, workflow engineering, architecture, selected projects, capabilities, and professional experience.

## Content model

The portfolio uses a progressive-enhancement approach:

- `index.html` provides the main static structure and fallback content.
- `styles.css` provides the visual system and responsive layout.
- `script.js` adds interactive behavior and workbook-backed enhancement.
- `portfolio-data.xlsx` is the editable structured content source used by the site.

## Privacy and publishing

Public portfolio content is intentionally sanitized. Private repository source, credentials, customer data, and confidential implementation details are not published here.
